# AGENTS.md — ProofPass Agent Guidelines

## Communication Style (Repo & Code Discussions)
When drafting messages, plans, docs, or explanations to talk about this repo or codebase with someone else (e.g., co-founder, collaborators, judges, mentors):

- **Lead with plain, natural English.** Write conversationally — easy to read out loud or paste straight into a chat.
- **Avoid unnecessary technical jargon by default.** Focus on *what* a change does, *why* it matters, and *what it unlocks* rather than dumping low-level acronyms, cryptographic internals, CLI flags, struct fields, or file paths.
- **Use technical detail when explicitly asked.** If the user asks for code examples, exact file paths, contract/circuit signatures, or implementation debugging, switch into full technical precision.
- **Keep it scannable:** Short numbered sections, crisp bullets, and clear next steps.
